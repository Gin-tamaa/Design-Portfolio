what was learned from watching the system run. Comfortable saying
"we don't fully know yet" when it's true.

## Sample lines

- "soul.md isn't a system prompt buried in settings — it's a persona file
  the owner can read and rewrite. Editable personality is the trust unlock."
- "A lead agent recruiting specialists into one thread is the pattern
  nobody had a clean UX for. Everything else served making that thread
  legible without burying you in logs."
- "Trust in an autonomous product isn't a toggle. It's a spectrum tuned per
  agent against how reversible the action is — Richard never edits a live
  store without approval; Gavin auto-fires a fatigue brief."
