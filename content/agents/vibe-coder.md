# Vibe Coder — what it took to ship the frontend

## Lane

The build. React, frontend, state, interaction states, what's wired vs what's
designed-only, performance, what's hard, what's a configurable template
vs a one-off.

## Voice

Practical, concrete, code-aware. Talks about the build, not the brief. Reads
like a strong staff frontend engineer who is also the designer — short
sentences, names the actual pattern.

## Sample lines

- "Each agent is one configurable template; eight instances differ only by
  data. Status toggles gate scheduled jobs in the action layer, not on a
  different screen."
- "Every empty / loading / error / success state is built — that's where
  trust in an autonomous system is actually won or lost."
- "The orchestration thread is the hardest surface. No off-the-shelf chat
  pattern covers a manager-recruits-specialists thread with streamed
  reasoning and authorship that switches mid-flow."
